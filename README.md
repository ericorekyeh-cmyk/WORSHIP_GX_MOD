# Worship GX Music Mod

A simple Opera GX-style mod with a dark neon visual theme and a music toggle.

## Included files
- manifest.json
- theme.css
- music.js
- 1102902.jpg

## Use your MP3
1. Put your MP3 file in this folder.
2. Name it one of these: `track.mp3`, `music.mp3`, `song.mp3`, `worship.mp3`, or `audio.mp3`.
3. Load the folder as the mod package in Opera GX.
4. Click the floating Worship GX button to play the track.

## Notes
- If no MP3 is found, the mod falls back to a built-in synth loop so it still works.
- The mod uses a dark neon palette and a floating music control for a GX-inspired mood.

## Customization
- Edit the colors in manifest.json under the theme block.
- Edit the audio list in music.js to change the file name or trigger behavior.
